# CI 分发方案：GitLab CI 对应关系 & 上传到蒲公英 / Firebase

## 一、GitHub Actions 与 GitLab CI/CD 的对应关系

| GitHub Actions | GitLab CI/CD |
|---|---|
| `.github/workflows/*.yml` | 仓库根目录 **`.gitlab-ci.yml`** |
| `runs-on: macos-latest` | **`tags:` 指定 runner**（GitLab 用标签选机器） |
| `steps:` / `run:` | `script:` / `before_script:` |
| `env:` + `secrets.*` | `variables:` + 项目设置 → CI/CD → **Variables**（勾选 Masked/Protected 等同于 Secret） |
| `on: push/pull_request` | `rules:` / `only:` / `workflow:rules:` |
| `actions/upload-artifact` | `artifacts:` + `paths:` |
| `actions/cache` | `cache:` + `key:` |
| `concurrency:` | `resource_group:` |

### 关键差异：GitLab.com 没有 macOS 共享 runner

**gitlab.com 官方共享 runner 只有 Linux / Windows，没有 macOS。** 要跑 iOS 构建必须自备 Mac：

1. 在一台常开的 Mac 上安装：

```sh
brew install gitlab-runner
```

2. 注册 runner，executor 选 **`shell`**，tag 填 `macos`：

```sh
gitlab-runner register
```

3. 项目设置 → CI/CD → Runners 中能看到它，`.gitlab-ci.yml` 里用 `tags: [macos]` 指定。

备选：MacStadium / MacinCloud / AWS EC2 Mac 这类云 Mac。GitHub 之所以方便，就是它白送 macOS runner。

### 本项目对应的 `.gitlab-ci.yml`

```yaml
stages:
  - build

ios_beta:
  stage: build
  tags:
    - macos                 # 自托管 Mac runner 的标签
  resource_group: ios-ci    # 串行，避免并发改证书
  before_script:
    - bundle install
  script:
    - printf '%s' "$ASC_PRIVATE_KEY" | openssl base64 -d -A > auth_key.p8
    - |
      KEYCHAIN_PATH="$TMPDIR/app-signing.keychain-db"
      printf '%s' "$BUILD_CERTIFICATE_BASE64" | openssl base64 -d -A > /tmp/build_certificate.p12
      printf '%s' "$DEVELOPMENT_CERTIFICATE_BASE64" | openssl base64 -d -A > /tmp/dev_certificate.p12

      security create-keychain -p "$KEYCHAIN_PASSWORD" "$KEYCHAIN_PATH"
      security set-keychain-settings -lut 21600 "$KEYCHAIN_PATH"
      security unlock-keychain -p "$KEYCHAIN_PASSWORD" "$KEYCHAIN_PATH"

      for g in G4 G5 G6; do
        curl -fsSL -o "/tmp/wwdr_$g.cer" "https://www.apple.com/certificateauthority/AppleWWDRCA$g.cer" || true
        security import "/tmp/wwdr_$g.cer" -k "$KEYCHAIN_PATH" || true
      done

      security import /tmp/build_certificate.p12 -P "$P12_PASSWORD" -A -t cert -f pkcs12 -k "$KEYCHAIN_PATH"
      security import /tmp/dev_certificate.p12   -P "$P12_PASSWORD" -A -t cert -f pkcs12 -k "$KEYCHAIN_PATH"
      security set-key-partition-list -S apple-tool:,apple: -k "$KEYCHAIN_PASSWORD" "$KEYCHAIN_PATH"
      security list-keychain -d user -s "$KEYCHAIN_PATH"

      security find-identity -v -p codesigning "$KEYCHAIN_PATH"   # 应输出 2 个有效身份
    - bundle exec fastlane beta
  rules:
    - if: '$CI_COMMIT_BRANCH == "main"'
  artifacts:
    paths:
      - output/*.ipa
```

## 二、上传到蒲公英 / Firebase App Distribution

### 前提：当前 ipa 装不上手机

现在 `beta` lane 用的是 `export_method: "app-store"`，这种包只能上传 App Store / TestFlight，**手机不能直接安装**。分发平台需要的是：

| 导出方式 | 谁能安装 | 前提 |
|---|---|---|
| `ad-hoc` | 已登记的测试机 | 设备 UDID 要在开发者后台登记（每年上限 100 台/设备类型） |
| `development` | 已登记的测试机 | 同上 |
| `enterprise` | 任意设备 | 必须有 299 美元企业开发者账号 |

### 1. 加一条临时分发的 lane

```ruby
lane :beta_adhoc do
  api_key = app_store_connect_api_key(
    key_id: ENV["ASC_KEY_ID"], issuer_id: ENV["ASC_ISSUER_ID"],
    key_filepath: "./auth_key.p8", duration: 1200
  )

  build_app(
    project: "Lobah.xcodeproj",
    scheme: "Lobah",
    configuration: "Release",
    export_method: "ad-hoc",          # ← 与 TestFlight 的唯一关键差异
    output_directory: "./output",
    output_name: "Lobah.ipa",
    xcargs: signing_xcargs
  )
end
```

设备 UDID 未登记时先补录（`fastlane/devices.txt` 每行一个 UDID）：

```ruby
lane :register_devices do
  api_key = app_store_connect_api_key(
    key_id: ENV["ASC_KEY_ID"], issuer_id: ENV["ASC_ISSUER_ID"],
    key_filepath: "./auth_key.p8", duration: 1200
  )
  register_devices(devices_file: "./fastlane/devices.txt", api_key: api_key)
end
```

### 2. 上传到蒲公英

不需要装插件，直接调 API v2。GitHub Secret 需要 `PGYER_API_KEY`（蒲公英账号 → API 信息）与可选的 `PGYER_INSTALL_PASSWORD`：

```yaml
      - name: Upload to Pgyer
        run: |
          curl -F "file=@output/Lobah.ipa" \
               -F "_api_key=${{ secrets.PGYER_API_KEY }}" \
               -F "buildInstallType=2" \
               -F "buildPassword=${{ secrets.PGYER_INSTALL_PASSWORD }}" \
               -F "buildUpdateDescription=CI 构建 ${GITHUB_SHA}" \
               https://www.pgyer.com/apiv2/app/upload
```

### 3. 上传到 Firebase App Distribution（二选一）

**A. firebase CLI（不用改 Gemfile）**

```yaml
      - name: Upload to Firebase App Distribution
        env:
          FIREBASE_TOKEN: ${{ secrets.FIREBASE_TOKEN }}
        run: |
          npm install -g firebase-tools
          firebase appdistribution:distribute output/Lobah.ipa \
            --app ${{ secrets.FIREBASE_APP_ID }} \
            --groups "testers" \
            --release-notes "CI 构建 ${GITHUB_SHA}" \
            --token "$FIREBASE_TOKEN"
```

- `FIREBASE_TOKEN`：本地执行 `firebase login:ci` 获取
- `FIREBASE_APP_ID`：形如 `1:123456789:ios:abcd1234`，在 Firebase 项目设置中查看

**B. fastlane 插件**

`Gemfile` 增加一行后执行 `bundle install` 更新 `Gemfile.lock`：

```ruby
gem "fastlane-plugin-firebase_app_distribution"
```

```ruby
firebase_app_distribution(
  app: ENV["FIREBASE_APP_ID"],
  firebase_cli_token: ENV["FIREBASE_TOKEN"],
  groups: "testers",
  release_notes: "CI 构建"
)
```

### 4. 建议的切换方式

一次构建同时给 TestFlight + 蒲公英 / Firebase 会比较重（需要导出两种 profile）。更实际的是用 `workflow_dispatch` 选择目标：

```yaml
  workflow_dispatch:
    inputs:
      signing_mode:
        description: '签名方式'
        required: true
        default: 'p12'
        type: choice
        options:
          - p12
          - stateless
      target:
        description: '分发目标'
        required: true
        default: 'testflight'
        type: choice
        options:
          - testflight
          - pgyer
          - firebase
```

## 附：相关 Secrets 一览

| Secret | 用途 |
|---|---|
| `ASC_KEY_ID` | App Store Connect API Key ID |
| `ASC_ISSUER_ID` | App Store Connect Issuer ID |
| `ASC_PRIVATE_KEY` | p8 内容（原文或 base64 均可） |
| `BUILD_CERTIFICATE_BASE64` | Apple Distribution 证书 p12 的 base64（导出/TestFlight 用） |
| `DEVELOPMENT_CERTIFICATE_BASE64` | Apple Development 证书 p12 的 base64（archive 签名用） |
| `P12_PASSWORD` | 上述 p12 的导出密码（两张建议设成一致） |
| `KEYCHAIN_PASSWORD` | CI 临时钥匙串口令，任意非空字符串 |
| `PGYER_API_KEY` | 蒲公英 API Key |
| `PGYER_INSTALL_PASSWORD` | 蒲公英安装密码（buildInstallType=2 时需要） |
| `FIREBASE_APP_ID` | Firebase 应用 ID |
| `FIREBASE_TOKEN` | firebase CLI 令牌（`firebase login:ci`） |
